# PT-04 — Regressão logística

Abra `regressao_logistica.ipynb` para consultar a resolução executada das quatro
partes e do bônus de `Exercicio_Regressao_Logistica.pdf`. O modelo já foi
treinado no enunciado; não é necessário baixar dados nem ajustar coeficientes.

Para reproduzir, execute nesta pasta:

```bash
python -m pip install -r requirements.txt
python build_pt04.py
python build_relatorio.py
```

O script gera o notebook com tabelas, gráficos e verificações numéricas. Também
é possível executar todas as células diretamente no Jupyter ou VS Code,
selecionando o ambiente Python em que as dependências foram instaladas.

A Parte 1 usa A–D; a Parte 3 usa as probabilidades fornecidas para E–I.
As escolhas de limiar explicitam suas hipóteses econômicas. Como não há
rótulos observados, não são inventadas métricas de desempenho.
